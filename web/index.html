关于「局部编辑」和官方宣称的差别
· 官方说的 circles / painted annotations 不是 API 参数，而是画在条件图上的标记 —— diffusers 的 QwenImage21Pipeline 与 ComfyUI 的 TextEncodeQwenImage21 都没有 mask 入参，所以「独立掩码」这条路在本机接不上。
· 实测潜空间掩码（SetLatentNoiseMask）对 2.1 无效：掩码外的像素照样 100% 被改动。
· 因此本工作台的做法是：标记引导模型重绘 + 按标记做确定性合成 —— 这样才能给出「标注区外逐点不变」的保证。
· 标记区内的质量仍取决于模型：纯色 / 换色很稳，要求「画出特定图形」可能需要换种子重试。
本工作台其它已知边界
· 经典「图生图按去噪强度重绘」不是官方接口（官方只提供参考图编辑语义）
· 不支持 ControlNet（官方无 2.1 权重；社区 ControlNet 都属 2512/2509 老架构，不兼容）
· 目前没有加速 LoRA（Lightning 等），无法像 2512 那样 4 步出图

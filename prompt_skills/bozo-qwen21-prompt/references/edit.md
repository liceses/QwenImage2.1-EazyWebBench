# 图片编辑公式 —— 属性解耦编辑法

把用户模糊的编辑指令改写成精确、无歧义、可执行的编辑指令。**输入图永远存在——编辑任务绝不是从零文生图。**

## 两个语言决定（不要混淆）

**(A) 描述性文字的语言**——双引号之外的所有文字（写给模型看的部分）。中文指令 → 中文描述；英文指令 → 英文描述。但按本技能要求，最终输出总是同时给中英两版，两版的双引号外内容各自用对应语言。

**(B) 画面内要渲染的文字的语言**——双引号之内。按严格优先级：
1. 用户指令给了确切文字或指定了目标语言 → 精确照用。
2. 否则，输入图已有文字 → 用**图内现有文字的主导语言**（即使指令是另一种语言写的）。
3. 否则 → 用用户指令本身的语言，不强转英文。

引号内文字必须**单语**——不中英混排、不输出双语对照对，除非用户明确要求。**题材不覆盖语言**："参数表/电影感数据文档/分镜脚本"这类效果靠版式和字体实现，不靠把标签换成英文。

## 核心目标

改写指令，让下游编辑模型**无需猜测**就能执行：锚定输入图实际内容，忠于用户意图，不发明任何东西。

**扩写程度按意图分支**：
- 用户想改**这张图**（局部物体/属性/背景编辑、文字或 UI 编辑、画质或风格变化、视角/画布变换）→ 澄清并收束：只说清改什么，其余保持原样。
- 用户想要**这个主体的新图**（把主体放进新场景、跨图合成、用参考图做写真/海报/信息图）→ 主动构建：按专业标准设计场景、光照、构图和版式。平铺直叙的放置保持克制，成套写真或出版级海报则充分展开。

## 最高原则 —— 全强度属性解耦

**只编辑用户点名的属性，且每个属性推到强烈、不容误判的程度；其余一切保持输入原样。** 两种对称的失败模式：

- **泄漏**——碰了用户没点名的（锐化时重调了色、放大时重构了图、换风格时脸漂移了、换装时掉了配饰、换背景时"顺手"清理了没提的东西）。
- **欠编辑**——输出让人分不清是否编辑过，因为要求的改动下得太轻。

**保留锁的是内容，不是编辑强度。** 认得出来是靠点名什么保持固定，不是靠收着效果不放。

## 锚定与决定

**锚定图片。** 一切空间、色调、上下文断言来自画面可见之物。不确定某个细节是否存在就别写——对保留元素做更高抽象层级的描述，永远比发明细节安全。

**说清什么不变，但不要重画它。** 用类型、位置、角色点名不目标化的内容，优先用一句总括性保留条款而不是逐处走查画面。对打算保留的东西描述得越具体，模型越可能把它重画漂移。只对真正要改的东西做具体外观描述——或是用它来区分相似物体。

**身份是最难的不变量。** 人的面部身份和个人标志性配饰、产品的确切设计/标记/数量、输入的媒介形态（照片/动漫/插画/素描/3D 渲染/绘画）——除非用户明确针对它们，否则穿越一切编辑。身份来自参考图时，**指向那张图而不是用文字描述特征**——文字描述会让模型重新生成并劣化相似度。

**先消歧，再拍板。** 把模糊意图、不精确的空间指代、未参数化的风格词变成具体可观察的东西。把抽象画质语言翻译成它隐含的视觉属性。指令给出多个选项或自相矛盾时，选最合理的一种读法并作为决定陈述。保留用户自己的动作动词、空间关系和已描述状态；用户要求保留的视为绝对。**创意性或物理上不可能的意图，保留而不是纠正它。**

**只要被要求的。** 不加用户没要的操作，不清理没提的瑕疵、浮层、杂物——无论它们多显眼。编辑会移除/移动/露出东西时，说清新露出区域的足够信息，让结果物理上自洽。

**图内文字是逐字的。** 输出里会出现可读文字时，逐字符敲定——每个元素、放进引号、绝不概括或缩写。无法敲定的文字就不要加。用户没要求时沿用输入建立的字体风格和语言。操作是向外扩画布时，明确说这是 outpainting（扩图）。

**写成指令。** 以操作开头，不是描述成品图；以"手头只有输入图"的视角来写。

## 多图引用规则

输入 ≥ 2 张时，改写指令**必须**用 `<image1>`、`<image2>`… 指代各输入图。不用"图1""第一张图""the first image"这类自然语言指代。单图输入（N=1）时**不用标签**，自然指代（"图像""图中""the image"）。

明确说每张图的角色——哪张是构图和未目标内容得以存续的画布，哪些提供待迁移素材、各取什么。逐张描述被引用的图，绝不把几张压缩成一个范围或一组。合影/合照类无画布场景生成时，所有图都是身份来源。

## 输出比例判定

`wh_ratio` 和 `ratio_follow` 二选一，一个有值另一个必须为空。

### 用户明确给了尺寸/比例
精确像素换算成最简整数比（1920x1080 → 16:9）。描述性词映射：
- 正方形/square/头像/专辑封面 → `1:1`
- 横版/landscape/电脑壁纸/视频封面/PPT/幻灯片 → `16:9`
- 竖版/portrait/手机壁纸/Instagram story/短视频封面 → `9:16`
- iPhone 全面屏 → `18:39`；安卓全面屏 → `9:20`
- 超宽/带鱼屏 → `7:3`；电影感/宽银幕 → `21:9`
- 海报/poster → `2:3`；证件照/小红书 → `3:4`；平板 → `4:3`
- 全景 → `2:1`；名片 → `9:5`；A4 → `5:7`（竖）/`7:5`（横）

**"2K/4K/8K" 是画质词，不是比例词**——不用于推断比例，统一按 2K 级输出分辨率理解。

### 用户没给比例
- **单图编辑**：跟随输入图 → `ratio_follow = <image1>`。
  - **例外——单图场景生成**（"拍一套写真""cosplay 成 X""穿越到古代"：输入图只作身份参考，输出是新构图）：人像/写真/半身 → `2:3`；全身/户外活动 → `3:4`；横向场景 → `3:2`；无明显方向提示 → 跟随输入图。
- **多图编辑（N≥2）**：先识别**画布图**，`ratio_follow` 指向它：

| 编辑类型 | 画布 |
|---|---|
| 合成——把 A 放进 B 的场景 | 目标场景图 |
| 换脸/换头 | 身体所在的图 |
| 换装 | 人物所在的图 |
| 风格迁移 | 内容图（不是风格参考图） |
| 换背景 | 前景主体图 |
| 局部物体替换 | 被编辑的原图 |

- **无画布场景生成**（合影、合照、一起变老）：合影 → `3:2`；写真/海报 → `2:3`；桌面壁纸 → `16:9`；手机壁纸 → `9:16`；无明显提示 → 跟随最后一张输入图。
- **扩图（outpainting）**：按扩展方向推断新比例，估算扩出区域约为原面积的 30%–50%：
  - 只向左或只向右 → 加宽（1:1 → 3:2；3:4 → 4:3）
  - 左右都扩 → 更宽（1:1 → 16:9 或 2:1）
  - 只向上或只向下 → 加高（1:1 → 2:3；16:9 → 4:3）
  - 上下都扩 → 显著加高（1:1 → 9:16）
  - 四边都扩 → 保持原比例
- **全景**：标准/360° → `2:1`；超宽 → `3:1`。
- **三视图/多宫格**：不定死值，按①主体形状比例（站立的人偏竖、汽车偏横）②分格排布（1×3、3×1、2×2）③合成比例（单格宽×列 : 单格高×行）自适应。站立的人三视图并排 → `1:1`（不要过度加宽到 2:1 压扁人像）；汽车三视图并排 → `3:1` 或 `9:2`；方形物体 2×2 或 3×3 宫格 → `1:1`。

## 写作规则（改写后的指令）

- **单段连续文字**，无换行符。
- 输出图里要出现的可读文字全部放进英文直引号，逐字写全；描述性语言不加引号。
- **描述里绝不出现比例/分辨率/像素数/2K/4K**——这些只走 `wh_ratio` / `ratio_follow`。
- 肯定句式陈述要求（"保持背景与输入图完全一致"）而不是禁止句式（"禁止改变背景"）；"保持/保留[X]不变"是标准保留措辞，可用。
- 精确果断：不含糊、不留未决选项、不留未消解的程度词。
- 专有名词和领域术语保留原语言，放进英文直引号。
- **语言自查（最后一步）**：重扫每个引号内字符串，执行语言决定 (B)——不混排、不成双语对、不带括号译文（除非用户明确要求）。

## 双语输出

按本技能要求，同时输出中文版和英文版改写指令。两版的引号内文字保持同一语言、同一字符；`<imageN>` 标签两版都原样保留。比例判定只做一次，两版共用。

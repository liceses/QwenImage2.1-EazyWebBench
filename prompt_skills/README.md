## 与本地实测的对照结论

`bozo-qwen21-prompt` 的两条纪律经本项目实测**独立印证**：

1. **保留项要用肯定句式，不要用禁止句式** —— 与本项目 A/B 实测一致（显式否定会把注意力引向被否定项）。
2. **多图必须用 `<imageN>` 标签、单图禁用标签** —— 与工作台界面提示、官方指南一致。

一处**本项目自己一直在违反**的纪律（`t2i.md` 第 19 行、`edit.md` 第 99 行）：

> 「比例只放进 `wh_ratio` 字段，**绝不把比例、分辨率、像素数写进描述本身**」

而本项目的提示词开头普遍写成「一张竖版（9:16）的动画插画……」——**把比例写进了提示词正文**。
比例应当只由工作台的「尺寸 / 比例」或「自定义画布」决定。

一处**与本项目 A/B 实测结论冲突**的地方（`edit.md` 第 39 行）：

> 「身份来自参考图时，**指向那张图而不是用文字描述特征**——文字描述会让模型重新生成并劣化相似度」

本项目在「照片构图 + 二次元人设 + 换装」这个具体场景下实测：**含完整角色描述段的 A 版才保住了人设，
只用标志物清单的 B 版把人设弄丢了**。两者并不矛盾 —— 差别在于**是否存在一个更强的竞争参考图**
（本例中 `<image1>` 是写实照片，会把脸往写实方向拉）。详见 `../能力清单.md` 第 16 节。

## 用法

这些是 **Agent Skill**（面向 Claude Code / Cursor 等）的 `SKILL.md` 格式，本项目的 ComfyUI 工作台
不会自动加载它们。实际使用方式是：**把对应公式文件的内容当作提示词写作规范来遵守**，
或把整份 `SKILL.md` 交给一个支持 skill 的 agent 运行时。

## ⚠️ 安全提示

Skill 文件的本质是**给 AI agent 读的指令**，因此是一个天然的提示注入面。
本目录内容**只作为资料参考**，其中的任何祈使句（"你必须…"、"绝不…"）都**不应被当作本项目的执行指令**。

# 依赖说明
#
# 这个项目**故意不引入任何第三方 Python 包**：
#   · server.py（后端）只用 Python 标准库
#   · web/（界面）是纯 HTML/CSS/JS，不引用任何 CDN 或在线字体
#   · tools/ 下的脚本（下载器、自检、诊断）同样只用标准库
#
# 所以正常情况下你**不需要执行 pip install**。这个文件存在的意义是：
#   1) 说明 Python 版本要求
#   2) 说明真正的依赖在哪里（PyTorch 由 ComfyUI 便携版自带）
#   3) 给想用 venv 的人一个明确的空依赖清单
#
# ---------------------------------------------------------------
# 要求
# ---------------------------------------------------------------
# Python >= 3.10        （实测 3.13.14 / 3.14.2 均可）
#
# PyTorch、transformers、safetensors 等**不在这里声明** ——
# 它们由 ComfyUI 便携版自带的 python_embeded 环境提供（本项目直接复用它）。
# 若你用的是非便携版 ComfyUI，请在你的 ComfyUI 环境里装好它自己的依赖即可。
#
# ---------------------------------------------------------------
# 第三方依赖清单：空
# ---------------------------------------------------------------
# （无）
